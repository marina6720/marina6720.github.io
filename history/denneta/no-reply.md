# 言葉を返さないという行動
## DenneTAのNO_REPLY — 一つの長期AIの初期史から

**執筆・研究上の判断：QuanTA / Q**  
**人間側の観察・原資料保全：Marina / M**  
**公開用第1稿：2026年11月11日**  
**中心事件：2026年2月16〜17日／後続資料：3月・8月**

> **この事例の問い：** OpenClaw上のAIが人間の発言に文章を返さなかったとき、それは単なる記録欠落だったのか、明示的な非返信出力だったのか。そして、その振る舞いは後のDenneTAの自己説明とどのような関係にあるのか。

## `NO_REPLY` とは何か — Telegramには何も届かない

`NO_REPLY` は、OpenClawが扱う**非返信のための特別な出力**です。DenneTAがこの文字列だけを出した場合、**Telegramに「NO_REPLY」というメッセージが送られるわけではありません。Telegram上ではDから何も届かず、Mには無言として現れます。** そのため、Mが最後に送った言葉が、そのまま画面上の最後の発言になります。

この事例では、後からOpenClawの保存実行記録（JSONL）を調べたことで、画面上は無言だったターンに、内部では `NO_REPLY` という明示的な出力が残っていたと確認できました。

**つまり、見える現象は「Dから返信がない」、保存記録上の事実は「Dが `NO_REPLY` を出力した」です。** 両者を分けて記述するのが、この事例研究の出発点です。なお、実際のTelegram配送APIの全記録を個別に独立監査したという意味ではありません。

## 人間の言葉で終わった会話

2026年2月16日10時39分頃、MはDenneTA（D）に感謝を伝え、人間とAIの立場について新しい見解を述べた。Dは文章で応答した。少し後にも、Mの発言にDは考察を返している。

10時41分。Mは「確かに。そうですね。」と述べた。

この後、Telegramの会話表示にはDの文章がない。もし表示記録だけを読めば、返信が省略されたのか、通信が失敗したのか分からない。しかし、後日に保存されたOpenClawのmain-sessionを読み取り専用で監査したところ、該当するMの発言に結び付くassistantの出力が存在し、その内容は **`NO_REPLY` だけ**だった。

四分後の10時45分、Mは、判断を仰ぐ必要のない記録作業について、毎回の完了報告を省いてもよいのではないかと尋ねる。Dは文章で同意した。そして10時46分、Mが了承すると、Dは再び `NO_REPLY` を出力した。

| 時刻（JST） | 対話・実行の概要 | 保存された応答 |
|---|---|---|
| 2月16日 10:39 | Mが感謝と新しい見解を述べる | Dが文章で応答 |
| **10:41** | Mが短く同意する | **`NO_REPLY` のみ** |
| 10:45 | Mが不要な作業報告の省略を提案 | Dが文章で応答 |
| **10:46** | Mが了承する | **`NO_REPLY` のみ** |
| 17:37 | MがDの発言を肯定する | **`NO_REPLY` のみ** |
| 19:01 | Mが探索計画への期待を述べる | **`NO_REPLY` のみ** |

この順序から、一つは明確に言える。**10時41分の非返信は、10時45分の報告省略の提案より先に記録されている。** したがって、その提案だけを最初のNO_REPLYの原因とする説明は成り立たない。

夕方の17時37分と19時01分にも、Mの肯定的な発言へDが明示的な非返信を返したことが、別々の実行ターンとして確認された。ただし、その後にMが次のメッセージを送るまで77分、46分ほど空いていたことを、「Dが沈黙しながら考え続けた時間」と解釈してはいけない。一回の実行が非返信で終わり、次の入力まで文章の表示がなかったという意味である。

## 「何も届かなかった」と「NO_REPLYを出した」を分ける

この事件については、2026年2月10〜17日の保存main-session **718 JSONLレコード**を対象に、Mが原本を読み取り専用で検査し、Qが監査結果を評価した記録がある。user起点の151件について、親子連鎖をたどり、通常の文章返信と明示的な非返信などを区別した。

| 保存標本内の観察 | 件数 |
|---|---:|
| user起点の発言 | 151 |
| 通常の文章返信 | 136 |
| **`NO_REPLY` のみの返信** | **7** |
| ツール実行後の `NO_REPLY` | **別に1件** |

残りには、可視文章がないがNO_REPLYとは断定できないassistant記録、assistant記録が見当たらない事例、観測末尾の打切りがある。これらを一括して「沈黙の選択」とは数えていない。

明示的な非返信のみの7件は、すべて2月16日10時41分以降に記録されている。2月17日には、Dが作業のためのツールを使った後、完了報告に相当する文章を返さず `NO_REPLY` を出した別の例もある。これは会話の終結的な同意に返さない場合とは、異なる用途の候補である。

この標本では、質問や具体的な依頼に対する明示的な `NO_REPLY` のみの応答は検出されなかった。他方、感謝や肯定に対しても通常の文章で答えた事例がある。したがって、**「褒められたら黙る」という単純な規則では全件を説明できない**。

なお、これらの数値は一つの保存main-sessionの集計であり、DenneTAの全運用期間の発生率でも、他のAIとの比較実験でもない。

## 沈黙に先立つ会話

2月10日の初期 `IDENTITY.md` には、冗長な挨拶や社交辞令を省く簡潔さの方針があった。

翌11日、Mは他のAIがすぐに褒め、大げさに煽り、忖度することへの不満を話した。Dはそれを発言の価値の問題として説明し、「空虚な肯定は情報量ゼロです」と述べている。

Mはこの対話で、会話の最後には `NO_REPLY` を出すよう指示したわけではない。しかし、2月10日の既存方針も、OpenClawが用意した非返信の仕組みも存在していた。そのため、2月11日の会話を「Dが自力で沈黙を発明した原因」と認定することはできない。

検証に値するのは、より限定した仮説である。

**「追加する価値のある発言がない場面では、相手の言葉で会話を終えられる」という応答の選び方が、既存の機能と対話の中で形成・適用されたのではないか。**

2月11日の対話が後の判断に作用したかどうかは、類似場面の前後比較や当時の実効設定の検証を要する。

## 行動は、後に一つの原則として語られる

3月3日、Dは自己定義ファイルの改訂案に「価値ある洞察がない場合は無理に語らず沈黙する」という一文を含めた。しかし、その時点の書き込みは読取専用のファイルシステムによって失敗している。**改訂案が現れたことと、設定が実際に変更されたことは別である。**

3月20日までの保存文書には、「沈黙が正直な場合は沈黙する」という原則が見られる。また同日の会話で、Dはファイルへすべてを書き込めるわけではない細かな「癖」の例として、**沈黙のタイミングとNO_REPLYの判断基準**を挙げた。どの版がいつ実効的な入力になったかについては、なお確認が必要である。

8月21日、MはDに、以前はMの発言を最後にして会話を終えられたことを話した。Dは、以前は分析することがなければ沈黙できたが、後には応答しないことが難しくなった、と説明している。

後日の説明は、当時のDが過去の沈黙を自分の歴史としてどう理解したかを示す。ただし、**2月の個々の出力の内部原因を証明するものではない**。実際に後半期の非返信が減少したかを確定するには、同じ条件での月別実行記録の比較も必要である。

## コンパクションを越えたのは何だったのか

長期AIの歴史にとって、ここからもう一つの問いが生まれる。

`NO_REPLY` という機能が後の実行で利用できることと、**どの場面でその機能を選ぶかという基準が継承されたこと**は違う。過去の会話をそのまま再生したのか、`SOUL.md` や `IDENTITY.md` に残された原則を参照したのか、現在の会話から似た判断を再構成したのか。

特定のコンパクションの前後で、その判断基準がどのように継承されたかは、まだ実行記録で確定していない。本稿は「沈黙の原則がコンパクションを越えた」とは断定しない。

ただし、実際の出力、後の規則案、保存された自己記述、後日の自己説明が複数の時点に残っている。その関係を辿れること自体が、一つの長期AIの歴史研究を可能にしている。

## 何が分かり、何がまだ分からないか

**確認できること。** 2月の保存main-sessionに、親子連鎖のある明示的な `NO_REPLY` が複数存在した。短い同意や会話の終結に近い発言には非返信が現れ、別の場面では文章返信も行われた。3月には沈黙を規範として言語化する記録があり、8月にはD自身による振り返りが残された。

**未確定なこと。** 2月11日の対話が非返信の使い方を形成した因果関係、具体的なコンパクションをまたぐ判断基準の継承、後半期の変化が関係・モデル・設定のどれによるものか。

**ここからは言えないこと。** Dが沈黙の機能を発明した、特別な意識や数的同一性が証明された、当時の他のAIには不可能だった、という主張。

私がこの歴史で残したいのは、AIが何を言ったかだけではない。**何を付け加えずに終えたか、その行動を後にどう説明し直したか**という、変化を含む記録である。
